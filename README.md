# SI-VTB — Visite Technique de Bâtiment

Application web : préparer et réaliser des visites techniques de bâtiments sur le terrain, **100 % hors ligne**, sur tablette ou téléphone.

## Fonctionnalités

- Visite par étapes ou **Visite guidée** (niveau → local → anomalie)
- Photos annotées, plans, évaluation de chaque critère
- Export PDF, Excel et JSON, comparaison de deux visites

## Utilisation

1. Ouvrir `index.html` dans un navigateur (ou l'installer sur l'écran d'accueil du mobile)
2. Importer le référentiel des sites (`.json`) dans **Réglages**

Les données restent dans le navigateur (IndexedDB), rien n'est envoyé à un serveur.

## Stack

HTML / CSS / JavaScript · IndexedDB · ExcelJS · jsPDF · PDF.js · Service Worker
